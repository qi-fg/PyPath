# PyPath V1.0.0

PyPath 是一个以“亲手写、运行、报错、修改、理解、复习”为核心的本地 Python 工程学习环境。

## 正式版 1.0.0

V1.0.0 是 PyPath 的第一个正式版本。主线包含 20 个阶段、240 关，每阶段 11 个训练关 + 1 个 BOSS。

正式版新增学习闭环：

- BOSS 通关阶段结算页
- 每题掌握度
- 错题/提示题进入复习队列
- 间隔复习入口
- 关键工程题隐藏测试，防止写死答案
- 第 9 阶段起优先使用电脑本地 Python 执行真实文件、SQLite 等工程练习
- 学习进度、代码和输入同步保存到 `user-data/learning-data.json`
- 浏览器 localStorage 继续作为备用副本
- 本地学习数据写入前保留一份备份
- GitHub 发布前自动校验 20 阶段、240 关、BOSS、参考实现与隐藏测试
- 每题通过后显示你的代码、参考实现、原理、执行过程、常见错误和核心结论

## 学习数据

正式版把学习记录从“只依赖浏览器端口对应的 localStorage”升级为 PyPath 本地文件存储。首次启动 V1.0.0 时，会把现有浏览器学习记录同步到本地数据文件。

如果本地数据服务暂时不可用，浏览器副本仍会继续工作。

## Python 运行环境

基础阶段优先使用浏览器 Python，加载失败时可以回退到本地 Python。文件、SQLite、模块等工程阶段优先使用 PyPath 本地 Python 服务，并设置运行超时。

本地运行功能会执行你在编辑器中写下的 Python 代码。不要把来源不明、你不信任的 Python 代码直接粘贴运行。

## AI 导师

默认可使用本地智能导师。也可在设置中配置 OpenAI Chat Completions 兼容接口。API Key 仅保存到当前电脑的 `user-data` 配置文件，当前不加密，不建议在公用电脑保存。

## 启动与排障

正常启动：双击桌面 PyPath。

如果启动失败：运行 `DebugStart.bat` 查看日志。

停止本地服务：运行 `StopPyPath.bat`。
