# PyPath V3.0.0

PyPath 是一个以“亲手写、运行、报错、修改、再理解”为核心的本地 Python 工程学习环境。

## V3.0.0：完整工程主线

V3.0.0 把旧版零散关卡重构为一条完整的工程 Python 主线：

- 20 个阶段
- 每阶段 12 关
- 共 240 关
- 每阶段前 11 关为技能训练
- 第 12 关为阶段 BOSS
- 每一关通过后自动显示完整详解
- BOSS 通过后解锁下一阶段
- 左侧按阶段折叠，不再一次堆出几百道题

主线阶段包括：Python 基础、字符串与输入、条件、循环、数据容器、字典、函数、调试、文件、模块与 CLI、OOP、标准库、SQLite、HTTP/API、测试、配置与日志、高级 Python、工程架构，以及最终综合工程挑战。

## 旧版学习记录迁移

如果你已经完成旧版前 12 关，V3 会自动把第 1 阶段标记为通关，并从第 2 阶段继续。旧版题目的代码缓存不会硬套到新课程，避免出现“题目和代码对不上”的情况。

## 每题详解

每次通关后会展示：

- 你的通过代码
- 参考实现（关键部分）
- 这题在考什么
- 为什么这样写
- 程序按什么顺序执行
- 常见错误
- 真正需要记住的结论

BOSS 关还会增加阶段能力复盘。

## 更新

PyPath 会通过 GitHub 更新频道检查新版。设置页支持“立即更新”，也保留本地 ZIP 安装作为兜底。更新时会保留 user-data、AI 配置和浏览器中的学习进度。

## AI 导师

默认可使用本地智能导师。也可以在设置中配置 OpenAI Chat Completions 兼容接口、模型名和 API Key。API Key 仅保存到本机 user-data 配置文件中，当前不加密，不建议在公用电脑保存。

## 启动与排障

正常启动：双击桌面 PyPath。

如果启动失败：运行 DebugStart.bat 查看本地服务日志。

停止本地服务：运行 StopPyPath.bat。
