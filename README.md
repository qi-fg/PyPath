# PyPath V2.1.1

这是 PyPath 的 GitHub 在线更新接入版本。V2.1.1 已绑定官方更新清单地址；以后启动 PyPath 时会自动检查 GitHub 上的新版本。

## 这次从 V2.0.1 升级

你当前已经有桌面 `PyPath` 快捷方式时：

1. 解压 `PyPath-V2.1.0.zip` 到任意临时目录。
2. 双击 `UpgradeExistingPyPath.bat`。
3. 它会找到桌面快捷方式正在使用的 PyPath 目录，停止旧服务，覆盖程序文件并重新打开 PyPath。
4. 原桌面快捷方式继续使用。
5. 浏览器中的学习进度不会因为程序文件覆盖而删除。

如果这是全新安装，则把文件夹放到固定位置，再双击 `CreateShortcut.bat` 一次即可。

## V2.1.0 新增

- 新的本地服务 `server.py`，仍然只监听 `127.0.0.1`。
- **内部安装更新包**：设置 → 版本与更新 → 选择更新包。PyPath 会验证版本、备份旧程序文件、覆盖更新并自动重启。
- **自由提问的智能导师**：右侧导师现在可以直接输入问题。
- **本地智能模式**：不配置 API 也能根据当前关卡、报错和提示级别回答常见问题。
- **可选 AI 模式**：设置中可以填写一个 OpenAI Chat Completions 兼容接口、模型名和 API Key。Key 只保存到本机 `user-data/ai-config.json`（当前为本地明文配置），不会通过网页接口返回完整 Key；不建议在公用电脑上保存。
- 自适应布局重做，减少窄屏和浏览器缩放时出现的横向滚动条。
- `user-data` 与程序文件分离，更新时不会覆盖 AI 配置。

## 以后怎么更新

从 V2.1.0 开始，后续正常流程是：

1. 下载我给你的新版 `PyPath-Vx.x.x.zip`。
2. 打开桌面 PyPath。
3. 点击右上角设置。
4. 点击“选择更新包”。
5. 选择刚下载的 ZIP。
6. PyPath 自动安装、自动重启、刷新到新版。

不需要再删除旧版，不需要重新创建桌面快捷方式，也不需要手动复制文件。

## AI 导师说明

默认无需任何 Key，会使用本地智能导师。

如果要启用真正的 AI：

1. 设置 → AI 导师。
2. 勾选“启用 AI 导师”。
3. 填写接口地址、你账号可用的模型名、API Key。
4. 保存。

接口需要兼容常见的 OpenAI `chat/completions` 请求与响应格式。若填写的是以 `/v1` 结尾的地址，PyPath 会自动补上 `/chat/completions`。

## 故障排查

正常启动：双击桌面 `PyPath`。

如果启动失败：运行 `DebugStart.bat`，它会显示本地服务错误并保留日志。

停止本地服务：运行 `StopPyPath.bat`。
